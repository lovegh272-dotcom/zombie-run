Zombie Run v112
- ออนไลน์เลือกโหมดได้ (โฮสต์เลือกในห้องรอ): ป้องกันรถ / ไม่จำกัด / รอด 15 นาที / รอด 30 นาที · ชนะแล้วเพื่อนเห็นหน้าชนะด้วย
- ตั้งชื่อห้องได้ (แท็ก ✏️ ชื่อห้อง · จำค่าไว้) · โชว์ในห้องรอและหน้าหาห้อง
- หน้าเล่นออนไลน์/หาห้อง โชว์ "ห้องสาธารณะ X ห้อง · ผู้เล่น Y คน" (นับเฉพาะห้องสาธารณะ)
- แก้ปุ่มในกล่องรหัสห้องซ้อนกัน · แก้แชทซ้ายล่างทับเนื้อหาห้องรอ (เนื้อหาขยับไปทางขวา)
- แก้ข้อความแชทอยู่หลังเมนูหยุดเกม (ตอนนี้อยู่บนสุด อ่านและคุยได้ระหว่างหยุด)
- ตั้งค่า: หัวข้อ "ข้อมูล" (เปิดโหมดนักพัฒนาแล้วจึงขึ้น "ข้อมูล / นักพัฒนา") · ใส่ไอคอนนักพัฒนา (ic_dev) ในตั้งค่า แผงนักพัฒนา และห้องรอ
- ทุกเครื่องต้องเป็น v112

งานที่ค้าง
1. โหมดผู้ชม (เข้ามาดูอย่างเดียว)
2. TURN server — ต้องสมัครบริการ (เช่น Metered/Twilio) แล้วเอาค่าใส่ NET_ICE.config.iceServers
3. เอฟเฟกต์ท่าไม้ตายของเพื่อนบางตัวยังไม่ครบ (netAura แบบทั่วไป)
4. บัค "เริ่มเกมแล้วเสียเลือด" รอรายละเอียด
5. โหมดอพยพ/บอสรัช/ท้าทายรายวัน ยังเล่นออนไลน์ไม่ได้ (มีเงื่อนไขเฉพาะของโหมด)
