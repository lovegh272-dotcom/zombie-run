Zombie Run v103

1) Firebase ประหยัดโควตา: เชื่อมต่อเฉพาะตอนเปิดหน้าหาห้อง / เปิดห้องสาธารณะในห้องรอ · ออกจากหน้า หรือเริ่มเกม = ตัดการเชื่อมต่อ
   (ห้องสาธารณะหายจากรายการระหว่างเล่น แล้วประกาศใหม่อัตโนมัติเมื่อกลับห้องรอ)
2) ร่างแปลง/ออร่า: ร่างอสูรยักษ์ (ท่าไม้ตายนักล่าคลั่ง), โหมดคลั่ง, ท่าฟัน, เงาตามตัว และออร่าตอนท่าไม้ตาย
   เห็นถูกต้องทั้งสองจอ ทั้งของโฮสต์และของเพื่อน · ร่างแปลงของเพื่อนหมดเวลาถูกต้อง
3) แชท/เมนู:
   - ป้าย "(ชื่อ) กดหยุดเกม" อยู่ใต้หัวข้อ "หยุดเกม" ในเมนูแล้ว (ไม่ลอยทับช่องพิมพ์)
   - แถบแชทในเกม: ตอนมีเมนูเปิด ย้ายไปช่องว่างด้านซ้ายของเมนู และอยู่ชั้นหน้าสุด
   - แชทห้องรอ: ความกว้างพอดีช่องว่างด้านซ้าย ไม่ทับการ์ดเมนู
   - คีย์บอร์ดเด้ง: แถบแชทเลื่อนขึ้นติดเหนือคีย์บอร์ด
4) เสียง (iPhone/iPad):
   - เปิดไมค์ครั้งแรกขออนุญาตครั้งเดียว หลังจากนั้นปุ่ม 🎤 = ปิด/เปิดเสียงไมค์ (ไม่ตัดไมค์ทิ้ง) → ระบบเสียงไม่สลับ เสียงเกมไม่หาย
     (ไอคอนไมค์ของ iOS จะค้างจนกว่าจะออกจากห้อง)
   - ปลุกเสียงเกมกลับอัตโนมัติหลังกดไมค์ / กลับเข้าแอป / แตะจอ
   - ลดเสียงเกมเหลือ 30% ระหว่างไมค์เปิด หรือเพื่อนกำลังพูด → เสียงเกมหลุดเข้าไมค์น้อยลง (ใส่หูฟังดีที่สุด)
