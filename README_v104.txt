ที่เปลี่ยนในเกม
- HUD บนจอ: เวลา / ฆ่า / ดาว / ชิ้นโบราณ เป็นรูป · โหมดป้องกันรถ: คลื่น / เศษเหล็ก / % รถ เป็นรูป · ลูกศรชี้รถเป็นรูปรถ
- ปุ่ม แชท / ไมค์ / เสียงเพื่อน / นักพัฒนา เป็นรูปกรอบเหล็กทั้งปุ่ม · สถานะใช้แสงเรือง (ไมค์เปิด=เขียว, เพื่อนพูด=เหลือง, ต้องแตะเพื่อฟัง=ส้ม)
- ปุ่ม สร้าง/ซ่อม และ "เริ่มเลย" ในโหมดป้องกัน มีไอคอน
- หน้าออนไลน์ / หาห้อง / ห้องรอ: ทุกปุ่มและแท็กใช้ไอคอนใหม่ (โฮสต์ มงกุฎ, พร้อม, รอ, เตะ, ส่งรหัส, สาธารณะ/ส่วนตัว, ออกห้อง)
- เมนูเลือกโหมด/ความยาก: ฝันร้าย, วันสิ้นโลก, รอด 30 นาที, อพยพ, ป้องกันรถ, ป้องกันไม่จำกัด, บอสรัช, ท้าทายรายวัน ใช้ไอคอนของตัวเอง
- ตัวเลขเศษเหล็กในหน้าเมนูสร้างป้องกัน เป็นรูปเฟือง
- โปรโตคอลออนไลน์ไม่เปลี่ยน (เล่นกับ v103 ได้)

ทดสอบ
1. หน้าเมนู > เล่นออนไลน์: ไอคอนปุ่มเล่นด่วน/หาห้อง/สร้างห้อง/เข้าห้องด้วยรหัส
2. สร้างห้อง ให้เพื่อนเข้า: ดูมงกุฎ/พร้อม/รอ/เตะ, ปุ่มไมค์-ลำโพงในแถวแชทซ้ายล่าง
3. เข้าเกมออนไลน์: ปุ่มแชท/ไมค์/เสียงเพื่อนมุมขวาบน เปิดไมค์ = มีแสงเขียว
4. โหมดป้องกันรถ: ดู HUD ล่างจอ + ปุ่มสร้าง/เริ่มเลย
5. ถ้าเห็นไอคอนเก่า ให้รีเฟรช/ล้างแคชเว็บ (cache = zrun-v104)
