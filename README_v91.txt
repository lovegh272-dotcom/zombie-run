Zombie Run v91 – ออนไลน์ขั้นที่ 3: ชุบสองทาง + ซ่อมรถช่วงพัก + เพื่อนเก็บของได้

ใหม่ (โหมดเล่นด้วยกัน)
- โฮสต์ล้มแล้วไม่จบเกมทันที → ล้มลงพื้น เดิน/ยิงปืนหลัก/ใช้สกิลไม่ได้ ซอมบี้หันไปไล่เพื่อนแทน
  เพื่อนไปยืนในวงประข้างๆ 3 วิ → โฮสต์ฟื้นครึ่งเลือด (อมตะ 2 วิ)
- จบเกมเมื่อ "ล้มทั้งทีม" หรือรถพัง (ในโหมดออนไลน์ไม่มีหน้าจ่ายเหรียญชุบ เพื่อไม่ให้เกมเพื่อนค้าง)
- ไอเท็มชุบชีวิตจากอัปเกรด (ถ้ามี) ยังทำงานก่อนเหมือนเดิม
- ผ่านคลื่นแล้ว ใครที่ล้มอยู่จะฟื้นเอง · เพื่อนได้เลือดคืน 30%
- เพื่อนเก็บคริสตัล XP ได้ (เข้า XP ทีม) และเก็บหัวใจเติมเลือดตัวเองได้ · เห็นคริสตัล/หัวใจบนจอเพื่อนด้วย
- ป้ายบนจอบอกสถานะทั้งสองฝั่ง เช่น "🆘 ... ล้ม! ไปยืนข้างๆ 3 วิเพื่อชุบ" พร้อมวงเปอร์เซ็นต์

ใหม่ (โหมดป้องกันรถ ทั้งคนเดียวและออนไลน์)
- ช่วงพักสร้าง ยืนใกล้รถ = ซ่อมรถ 1%/วิ ต่อคน (2 คนช่วยกัน = 2%/วิ) มี 🔧+ ลอยขึ้น

แก้บั๊ก
- เพื่อนเดินไปที่พิกัด x หรือ y = 0 แล้วตำแหน่งบนเครื่องโฮสต์ค้าง

มีอยู่แล้วก่อนหน้า (ตามแผน v91): คลื่นไม่จำกัดยากขึ้นเรื่อยๆ · บอสทุก 5 คลื่น · บอสภัยพิบัติทุก 10 คลื่น · พักสร้างระหว่างคลื่น

วิธีทดสอบ
1. อัปเดตเป็น v91 ทั้งสองเครื่อง (ถ้าเวอร์ชันไม่ตรง จะเข้าห้องไม่ได้)
2. โฮสต์ยืนให้โดนตีจนล้ม → เพื่อนไปยืนข้างๆ 3 วิ → โฮสต์ต้องฟื้น
3. ให้ล้มทั้งคู่ → ทั้งสองเครื่องต้องขึ้นหน้าสรุป
4. ช่วงพักสร้าง ไปยืนข้างรถทั้งคู่ → หลอดเลือดรถต้องขึ้นเร็วกว่ายืนคนเดียว
5. ให้เพื่อนเดินไปเก็บคริสตัล/หัวใจ → XP ทีมขึ้น และเลือดเพื่อนขึ้น
