Zombie Run v110
- หน้าหลักแสดง "เวอร์ชัน v110" ใต้โลโก้ (แก้เลขที่ const GAME_VER ใน index.html)
- โหมดป้องกันรถ: "ศัตรูคลื่นถัดไป" ใช้รูปซอมบี้จริงแทนอิโมจิ (บอส = ป้ายเตือนบอส)
- แชทด่วน: ปุ่ม ช่วยด้วย / มาซ่อมรถ / สร้างตรงนี้ / ระวังบอส / ชุบหน่อย มีไอคอน
- ออนไลน์เหมือน v108-v109 (เล่นด้วยกันได้)

งานที่ค้าง (ไว้ทำรอบหน้า)
1. ออนไลน์เล่นโหมดอื่น (ไม่จำกัด / รอด 15-30 นาที / บอสรัช) — ตอนนี้ netStartGame บังคับ S.mode='defendless'
2. เข้ากลางเกม (ดูก่อน แล้วเกิดตอนช่วงพักคลื่น) — ตอนนี้ netAccept ตอบ 'busy'
3. TURN server สำหรับเน็ตที่ต่อตรงไม่ได้ — เพิ่มใน NET_ICE.config.iceServers
4. เอฟเฟกต์ท่าไม้ตายของเพื่อนบางตัวยังไม่ครบ (netAura เป็นแบบทั่วไป)
5. บัค "เริ่มเกมแล้วเสียเลือด" ยังทำซ้ำไม่ได้ — รอรายละเอียดจากการเทส
