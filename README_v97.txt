Zombie Run v97 – เมนูนักพัฒนา (ไอคอน 🛠)

วิธีเปิด
1. ตั้งค่า → แตะหัวข้อ "ข้อมูล / นักพัฒนา" 7 ครั้ง (เปิดโหมดนักพัฒนาเหมือนเดิม)
2. เปิด "🛠 ไอคอนนักพัฒนา" → มีปุ่ม 🛠 ลอยมุมซ้ายล่าง (ทั้งหน้าเมนูและในเกม) กดอีกครั้งเพื่อปิดได้
   (ช่อง "ใส่รหัสโกง" เอาออกแล้ว ย้ายมาเป็นปุ่ม)

ปุ่มในแผง 🛠 (เกมไม่หยุดตอนเปิดแผง)
- บัญชี: 🪙 +99,999 เหรียญ · 🔓 ปลดล็อกตัวละคร/แผนที่/ด่านเนื้อเรื่องทั้งหมด
- ตัวละคร: 🛡️ อมตะ · ⚡ สกิลไม่มีคูลดาวน์ (รวมท่าไม้ตาย) · ⬆️ เลเวลอัป
- เร่งเวลา: ×1 ×2 ×3 ×5 ×10 (×10 กินเครื่องมาก อาจกระตุก)
- ซอมบี้: 💀 ฆ่าทั้งจอ · 👹 เรียกบอส
- โหมดป้องกันรถ: ⏭ ข้ามคลื่น · ⚙️ เศษเหล็กไม่จำกัด · 🧱 สร้างไม่จำกัด (ไม่มีลิมิตชิ้น/ป้อมยิง) · 🚚 ซ่อมรถเต็ม
- ระบบ: 📊 FPS · 📈 บันทึกประสิทธิภาพ (จากหน้าเมนู)
- ปุ่ม 🛠 เปลี่ยนเป็นสีส้มเข้มเมื่อมีโหมดทดสอบเปิดค้างอยู่

ออนไลน์
- โฮสต์ใช้ได้เสมอ (ถ้าเปิดไอคอนไว้)
- เพื่อนใช้ได้เมื่อ "เปิดไอคอนทั้งสองคน" · ห้องรอแสดง "🛠 โหมดทดสอบ: ชื่อ ✅/❌"
- คำสั่งที่กระทบทั้งเกม (ฆ่าทั้งจอ/บอส/ข้ามคลื่น/เศษเหล็ก/อมตะของเพื่อน) ส่งให้เครื่องโฮสต์ทำ · เร่งเวลา/เลเวลอัปเฉพาะโฮสต์

ทดสอบแล้ว: Chromium — อมตะ, เศษเหล็กไม่จำกัด, สร้างไม่จำกัด, เร่ง ×5 (เวลาเกมเดิน 4.25 วิ ต่อ 1 วิจริง), ฆ่าทั้งจอ, เรียกบอส, ไม่มีคูลดาวน์, เลเวลอัป, ธงโหมดทดสอบในห้อง (ไม่มี error)
