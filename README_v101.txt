Zombie Run v101 (รวม v100) – สกิลจริง + คู่หูของเพื่อนครบทุกตัวละคร

⭐ สกิลเฉพาะตัวของเพื่อน (v100)
- เพื่อนใช้สกิลจริงของตัวละครตัวเองทั้ง 4 ปุ่ม (พุ่ง / ระเบิด / โล่ / ท่าไม้ตาย) ครบ 11 ตัว — เหมือนตอนเล่นคนเดียว
  เช่น นักดาบพุ่งฟันทะลวง+ม่านดาบ, ผู้ควบคุมฟ้าสนามไฟฟ้า+ฟ้าชิ่งลูกโซ่, นักล่าคลั่งพุ่งคลั่ง+ออร่าเพลิง, พ่อมดโดมกระดูก+ราชาโครงกระดูก ฯลฯ
- วิธีทำ: ย้ายโค้ด "สกิลที่ทำงานต่อเนื่อง" ออกมาเป็นฟังก์ชัน skTick แล้วให้เพื่อนเรียกใช้สกิล/ท่าไม้ตายด้วยค่าของตัวเอง (สลับตัวผู้เล่นชั่วคราว แบบเดียวกับอาวุธหลัก)
- หมอ/นักบวช: ท่าไม้ตายยังฟื้นเลือดโฮสต์และชุบโฮสต์ที่ล้มได้เหมือนเดิม
- เอฟเฟกต์ภาพสกิล (ภาพสไปรต์สกิล/เส้นสไนเปอร์/ฟ้าผ่า/วงต่างๆ) ส่งไปเครื่องเพื่อน · เอฟเฟกต์ที่ติดตัวคนใช้ จะตามตัวคนนั้นถูกต้อง
- ท่าไม้ตายของเพื่อนไม่ทำให้จอโฮสต์กะพริบ

🐺 คู่หูของเพื่อน (v101)
- เรลิก 🔷 นับรวมทั้งทีม: โฮสต์เก็บเรลิก 1 ชิ้น = เพื่อนได้ 1 ชิ้นด้วย · ครบ 3 ชิ้น เพื่อนได้คู่หูประจำตัวละครของตัวเอง
  (โดรนรบ / ดาบวิญญาณ / หมาป่าเพลิง / นกฮูก / อัศวินศักดิ์สิทธิ์ ฯลฯ)
- คู่หูของทั้งสองคนเห็นทั้งสองจอ

ทดสอบแล้ว (Chromium): เล่นคนเดียวทั้ง 11 ตัว ใช้สกิลครบ 4 ปุ่ม + คู่หูทำงาน (ผลเหมือนเดิม) · เพื่อนเป็นทั้ง 11 ตัว ใช้สกิล 4 ปุ่ม + คู่หู ฆ่าซอมบี้ได้ · เครื่องเพื่อนได้รับเอฟเฟกต์และคู่หู (ไม่มี error)
ยังไม่ได้ทดสอบ: iPhone จริง · ความลื่นตอนสกิลใหญ่ๆ ของทั้งสองคนพร้อมกัน
ยังไม่รวม: ออร่ารอบตัวตอนท่าไม้ตายบางตัว (วาดจากตัวแปรของผู้เล่นหลัก) ฝั่งเพื่อนอาจยังไม่ขึ้น
