Zombie Run v129 — ต้นแบบโหมด Rooftop Run (ไฟล์แยก rooftop.html)
- เปิดด้วย rooftop.html ยังไม่ได้ต่อเข้าเมนูเกมหลัก
- ชั้น 1: 3 ห้อง ประตูกั้นซอมบี้ (ซอมบี้ทุบประตู) สวิตช์ไฟห้องละ 1 ต้องเปิดให้ครบก่อนขึ้นบันได
- ควบคุม: ◀ ▶ เดิน, เล็ง เปลี่ยนระดับยิง (ต่ำ/กลาง/สูง=หัว ดาเมจ 2), ยิง (กดค้างยิงอัตโนมัติ), ใช้ = E
- ดาดฟ้า: กดใช้ที่เสาสัญญาณ เฮลิคอปเตอร์มาใน 30 วิ แล้วเดินไปที่เฮลิคอปเตอร์เพื่อหนี
- ท่าปีนบันไดใช้เฟรมที่มีบันไดติดมา (ยังไม่ได้แยกชิ้น)
- ยังไม่มี: หลายชั้น, สกิลเดิม, ออนไลน์, เสียง, ระบบอัปเกรด
