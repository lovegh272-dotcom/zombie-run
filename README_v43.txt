- เสียงอาวุธแยกตามตัวละคร 9 ตัว (shoot_<id>) เช่น ไรเฟิล / สไนเปอร์มีเสียงสะท้อน / ลูกซอง+เสียงขึ้นลำ / ดาวกระจาย / ปาระเบิด / สายฟ้าแตกแปลบ / ปืนลูกดอก / กรงเล็บ / เวทผี
- เสียงเท้าตามจังหวะก้าว เปลี่ยนตามพื้นแผนที่ (หญ้า/คอนกรีต/กระเบื้อง/หิน)
- ซอมบี้ครางรอบตัวแบบสุ่ม ตัวใหญ่เสียงทุ้ม ตัวเร็วกรีดร้อง | ตายตัวใหญ่เสียงหนัก | บอสคำรามตอนโผล่ + เสียงเท้าบอส (เร็วขึ้นตอนพุ่ง)
- เสียงมีระยะ: ไกล = เบา + แพนซ้าย/ขวาตามตำแหน่ง (ซอมบี้ ตาย บอส)
- สุ่ม pitch เล็กน้อยทุกครั้ง กันเสียงซ้ำน่าเบื่อ (ยกเว้นเสียงดนตรี/ปุ่ม)
- เสียงปุ่มเมนู: คลิก / ย้อนกลับ / เปิดหน้า / สลับตั้งค่า / ซื้อไม่ได้ / การ์ดอัปเกรด | เปิดปิดได้ใน ตั้งค่า > เสียงปุ่มเมนู
- เปิดหีบมีเสียงของตัวเอง
- รองรับไฟล์เสียงจริง: snd/sounds.json + ไฟล์ใน snd/ (หลายไฟล์ต่อเสียง = สุ่มเล่น) ไม่มีไฟล์ = ใช้เสียงสังเคราะห์อัตโนมัติ
  เพลงจากไฟล์ bgm_menu / bgm_play / bgm_boss / bgm_dungeon เล่นวนพร้อมครอสเฟด (ไม่มี = เพลงสังเคราะห์ 4 ธีมเดิม)
