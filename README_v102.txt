Zombie Run v102 – รายชื่อห้องสาธารณะ (หาห้อง / เล่นด่วน)

หน้า 🌐 เล่นออนไลน์ ใหม่
- ⚡ เล่นด่วน: หาห้องสาธารณะที่ว่างแล้วเข้าให้เลย · ถ้าไม่มี จะสร้างห้องสาธารณะให้แล้วรอคนเข้า
- 🔍 หาห้อง: รายการห้องที่ว่าง (ชื่อโฮสต์ ตัวละคร แผนที่ ความยาก 1/2) อัปเดตสด · แตะเพื่อเข้า (ไม่ต้องพิมพ์รหัส)
  ไม่แสดง: ห้องเต็ม / ห้องที่เริ่มเล่นแล้ว / เวอร์ชันเกมไม่ตรง / ห้องร้าง (โฮสต์ปิดแอป ห้องหายเอง)
- 🌍 สร้างห้องสาธารณะ / 🔒 สร้างห้องส่วนตัว (ส่วนตัว = เข้าด้วยรหัสเท่านั้น เหมือนเดิม)
- 🔑 เข้าห้องด้วยรหัส (เหมือนเดิม)

ในห้องรอ
- โฮสต์กดสลับ 🌍 สาธารณะ / 🔒 ส่วนตัว ได้ตลอด · เพื่อนเห็นว่าเป็นห้องแบบไหน
- โฮสต์มีปุ่ม 🚫 เตะ ข้างชื่อผู้เล่น (คนที่โดนเตะ เข้าห้องนี้ซ้ำไม่ได้จนกว่าจะเปิดห้องใหม่)
- ห้องสาธารณะ: ปิดเมนูนักพัฒนาทั้งสองฝั่ง · ไมค์เริ่มต้นปิดอยู่แล้ว (ต้องกดเปิดเอง)

ต้องตั้งค่า (ครั้งเดียว)
- ตอนนี้ยังไม่ได้ใส่ค่า Firebase → หน้า "หาห้อง" จะขึ้นว่ายังไม่ได้ตั้งค่า · โหมดรหัสห้องใช้ได้ปกติ
- สร้าง Firebase Realtime Database แล้วส่ง firebaseConfig มา → ใส่ที่ FB_CFG ใน index.html
- Rules ที่ต้องวาง (Realtime Database > Rules):
{
  "rules": {
    ".read": false,
    ".write": false,
    "rooms": {
      ".read": true,
      ".indexOn": ["ts"],
      "$code": {
        ".write": "$code.matches(/^[A-Z0-9]{4}$/)",
        ".validate": "!newData.exists() || (newData.child('n').isString() && newData.child('n').val().length <= 16 && newData.child('pl').isNumber() && newData.child('v').isString() && newData.child('ts').isNumber())"
      }
    }
  }
}

ทดสอบแล้ว: Chromium 3 หน้า + Firebase จำลอง — ประกาศห้อง, หาห้องแล้วแตะเข้า, ห้องเต็มหาย, เตะผู้เล่น, เล่นด่วนเข้าห้องว่าง, สลับส่วนตัวแล้วห้องหายจากรายการ, เมนูนักพัฒนาปิดในห้องสาธารณะ (ไม่มี error)
ยังไม่ได้ทดสอบ: กับ Firebase จริง (รอค่า config)
