Zombie Run v113
- โหมดผู้ชม: หน้าเข้าห้องแตะ "👁 เข้าดูอย่างเดียว" หรือในหน้าหาห้องกด "👁 เข้าดู"
  ผู้ชมไม่นับที่นั่ง (ผู้เล่น 4 + ผู้ชมได้อีก 4) เข้าได้ทั้งก่อนและระหว่างเกม · กล้องตามผู้เล่น แตะปุ่มด้านล่างเพื่อสลับคน
  ห้องรอโชว์ "👁 ผู้ชม" และจำนวนผู้ชม · ผู้ชมไม่ต้องกดพร้อม
- ออนไลน์เพิ่มโหมด บอสรัช และ ท้าทายรายวัน (ใช้แผนที่+กติกาของวันนั้น)
- แชทในเกม: ตอนเปิดแชท ข้อความเรียงจากล่างขึ้นบน ติดกับกล่องพิมพ์ (ข้อความล่าสุดอยู่ล่างสุด)
- ทุกเครื่องต้องเป็น v113

งานที่ค้าง
1. โหมดอพยพออนไลน์ — ต้องส่งข้อมูลอะไหล่/เฮลิคอปเตอร์/ลูกศรให้เพื่อนเห็น (G.ex) ยังไม่ได้ทำ
2. เอฟเฟกต์ท่าไม้ตายของเพื่อน — ท่าที่ใช้สถานะ G เฉพาะ (เช่น thor/mini/ice/plane/dark) ยังวาดฝั่งโฮสต์และไม่ส่งให้เพื่อน
3. TURN server (ต้องสมัครบริการ)
4. บัคเริ่มเกมแล้วเสียเลือด (รอรายละเอียด)
