Zombie Run v92 – ออนไลน์ขั้นที่ 4: อาวุธจริงของทุกตัวละคร + สกิล + อัปเกรดแยกของแต่ละคน

ใหม่ (โหมดเล่นด้วยกัน)
- เพื่อนใช้อาวุธหลักจริงของตัวละครตัวเองแล้ว (ทั้ง 11 ตัว: ปืน/ดาวกระจาย/ระเบิดโค้ง/สไนทะลุ/ฟ้าผ่าชิ่ง/ลูกซอง/หมอ/นักล่าคลั่ง/พ่อมด/นารา/นักบวช)
  ใช้โค้ดยิงชุดเดียวกับผู้เล่นหลัก (ย้ายโค้ดยิงเป็นฟังก์ชัน fireMain แล้วให้เพื่อนเรียกใช้ด้วยค่าพลังของตัวเอง)
- เพื่อนกดสกิลได้ทั้ง 4 ปุ่ม (คูลดาวน์ตามตัวละคร):
  · ปุ่ม 1 พุ่ง (เร็ว + อมตะสั้นๆ) · ปุ่ม 2 ระเบิดรอบตัว + ผลัก · ปุ่ม 3 โล่ 4 วิ + เลือด 10% · ปุ่ม 4 ท่าไม้ตาย ระเบิดใหญ่
  · หมอ/นักบวช: ท่าไม้ตายฟื้นเลือดทั้งทีม 40% และชุบโฮสต์ที่ล้มอยู่ได้
  หมายเหตุ: สกิลของเพื่อนเป็น "เวอร์ชันออนไลน์" ที่เหมือนกันทุกตัว ต่างกันที่สี/คูลดาวน์ (สกิลเฉพาะตัวแบบละเอียดผูกกับระบบผู้เล่นหลักมากเกินไป)
- อัปเกรดแยกของใครของมัน: XP ยังรวมกันเป็นทีม แต่ทุกครั้งที่ทีมเลเวลอัป
  · โฮสต์: เลือกอัปเกรดของตัวเองอัตโนมัติ (เหมือน v90)
  · เพื่อน: มีแถบเลือก 3 ตัวเลือกโผล่ด้านบนจอ เกมไม่หยุด (ดาเมจ / ยิงเร็ว / กระสุน+1 / ทะลุ+1 / ระยะ / เลือดสูงสุด / เดินเร็ว / คูลดาวน์สกิล)
  · พลังเพื่อนไม่ผูกกับเลเวลโฮสต์แล้ว
- เห็นกระสุนพิเศษ (เช่นกะโหลกพ่อมด) และโล่ของอีกฝ่ายบนจอ

ทดสอบแล้ว
- Chromium 2 หน้าผ่าน PeerJS จำลอง: เพื่อนเป็นทั้ง 11 ตัวละคร ยิงได้ทุกตัว, สกิล 4 ปุ่ม, อัปเกรดส่งถึงโฮสต์, แถบเลือกอัปเกรดขึ้น (ไม่มี error)
- เล่นคนเดียวทั้ง 11 ตัวหลังย้ายโค้ดยิง ผลเท่ากับ v91
ยังไม่ได้ทดสอบ: อินเทอร์เน็ตจริงและบน iPhone

วิธีทดสอบ (2 เครื่อง อัปเดตเป็น v92 ทั้งคู่)
1. เพื่อนลองเลือกตัวละครหลายแบบ (เช่น สไนเปอร์ พ่อมด ลูกซอง) → ดูว่ายิงแบบตัวละครนั้นจริง
2. เพื่อนกดสกิลทั้ง 4 ปุ่ม → โฮสต์ต้องเห็นวง/ระเบิด/โล่ที่ตัวเพื่อน
3. เล่นจนเลเวลอัป → เพื่อนต้องมีแถบเลือกอัปเกรดด้านบน กดแล้วแรงขึ้นจริง
4. เพื่อนเป็นหมอ/นักบวช → ปล่อยให้โฮสต์ล้ม แล้วใช้ท่าไม้ตาย → โฮสต์ต้องฟื้น
