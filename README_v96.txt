Zombie Run v96 – แชทซ้ายจาง · หยุดทั้งห้อง · เมนูไม่หยุดเกม · อาวุธติดตัวของเพื่อน · ห้องรอใหม่ · ตัวหนังสือ iPhone

💬 แชทห้องรอ: ย้ายไปด้านซ้าย โปร่งจาง ปัดนิ้วเลื่อนขึ้นลงได้ ช่องพิมพ์อยู่ล่างซ้าย (หน้าห้องสั้นลง)
   ในเกม: ตอนเปิดแถบแชท ประวัติแชทด้านซ้ายปัดเลื่อนได้

⏸ หยุดทั้งห้อง (ออนไลน์): ใครกดหยุด เกมหยุดทั้งคู่ (เดินไม่ได้ทั้งคู่) · ขึ้น "⏸ (ชื่อ) กดหยุดเกม" · กดเล่นต่อได้ทั้งสองคน

▶ ออนไลน์: เปิดเมนูสร้าง / วางของ / เลือกคำสาป-พร → เกมไม่หยุดแล้ว (ระวังโดนตีระหว่างคลื่น)
   คำสาป/พรทุก 10 คลื่น จะรอให้ปิดเมนูก่อนแล้วค่อยขึ้น

🌀 อาวุธติดตัวของเพื่อน: นักดาบ/นักล่าคลั่ง (ดาบหมุน), นักขว้าง (ระเบิดมือ), ผู้ควบคุมฟ้า (ไฟฟ้า), นักลูกซอง (ลูกซอง)
   ทำงานจริงแล้ว (เดิมดาบค้างไม่หมุนและไม่ทำดาเมจ) · ดาบหมุนของอีกฝ่ายเห็นทั้งสองจอ

🏠 ห้องรอ
- เลือกตัวละครแบบแถบรูป เลื่อนซ้ายขวา ตัวที่เลือกกรอบเขียว
- โฮสต์เลือกแผนที่ (ที่ปลดล็อกแล้ว) และความยากได้ในห้อง · เพื่อนเห็นตาม (เปลี่ยนแล้วสถานะพร้อมรีเซ็ต)

📱 ตัวหนังสือ iPhone ใหญ่กว่า iPad: ปิดการขยายตัวหนังสืออัตโนมัติของ Safari แนวนอน (-webkit-text-size-adjust) + ย่อข้อความเมนูสร้างให้สั้นลง

ทดสอบแล้ว: Chromium 2 หน้าจำลองออนไลน์ — แชทซ้าย, โฮสต์เลือกแผนที่/ความยาก→เพื่อนเห็นและเข้าแผนที่เดียวกัน, ดาบหมุนเพื่อนฆ่าได้, เมนูเปิดแล้วเกมยังเดิน, หยุด/เล่นต่อทั้งห้อง (ไม่มี error)
ยังไม่ได้ทดสอบ: iPhone/iPad จริง (โดยเฉพาะขนาดตัวหนังสือ)
