Zombie Run v94.1 – แก้/ตรวจปัญหาค้างหน้าโหลดบน iPhone

อาการ: v94 บน iPhone ค้างที่ "กำลังโหลด..." (หลอดไม่ขึ้น ไม่มีคำแนะนำ) = โค้ดหยุดก่อนเริ่มหน้าโหลด
ตรวจแล้ว: Chrome เปิดได้ปกติ (ลองเซฟหลายแบบทุกโหมด) และ JavaScriptCore (เครื่องยนต์เดียวกับ Safari) อ่านโค้ดได้ไม่มี error → ยังหาสาเหตุบนเครื่องผมไม่เจอ

สิ่งที่แก้ใน v94.1
- ตัวแจ้ง error บนหน้าโหลด: ถ้ามีอะไรพัง จะขึ้นข้อความสีเหลือง "⚠️ เกิดข้อผิดพลาด..." พร้อมบรรทัดที่พัง (แคปส่งมาได้เลย)
  ถ้า 9 วิแล้วยังไม่บูตและไม่มี error จะโชว์รุ่น iOS/เบราว์เซอร์แทน
- บูตแบบปลอดภัย: ถ้าการตั้งค่าเริ่มเกมพัง (เช่น เซฟเสีย) ยังไปหน้า "แตะเพื่อเริ่ม" ได้ และรีเซ็ตค่าที่ผิดเป็นค่าเริ่มต้น
  (ตัวละครที่เลือกแต่ไม่มี → ทหาร · แผนที่/โหมด/ความยากที่ไม่ถูกต้อง → ค่าเริ่มต้น)
- กันเซฟเพี้ยนจากโหมดออนไลน์: ระหว่างเล่นออนไลน์ เกมจะไม่เซฟตัวละครของเพื่อน/โหมดป้องกันรถทับของคุณ
  (เดิมถ้าปิดแอปกลางเกมออนไลน์ อาจเซฟโหมด/ตัวละครผิดค้างไว้)

ถ้ายังค้าง
1. ปัดปิดแอป/แท็บให้หมด แล้วเปิดใหม่ (ให้โหลด v94.1)
2. ถ้ายังค้าง → แคปหน้าจอที่มีข้อความสีเหลืองส่งมา
3. ทางแก้ชั่วคราว: ตั้งค่า > Safari > ขั้นสูง > ข้อมูลเว็บไซต์ > ลบ github.io (ระวัง: เซฟเกมจะหาย)
