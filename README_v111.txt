Zombie Run v111
- เข้ากลางเกมได้: เพื่อนเข้าห้องระหว่างที่กำลังเล่นอยู่ จะเกิดข้างโฮสต์ทันที (อมตะ 3 วิ)
  โฮสต์ตั้งในห้องรอได้: แท็ก "เข้ากลางเกม: ได้/ไม่ได้" (จำค่าไว้) · หน้าหาห้องโชว์ "กำลังเล่น · เข้าได้"
- เล่นคนเดียวในห้องออนไลน์ได้: กดพร้อม > เริ่มเกม (เพื่อนเข้ากลางเกมทีหลังได้)
- สลับแอพ/หน้า: แจ้งทุกคน "⏸ ชื่อ สลับแอพ · รอ 30 วิ" ตัวละครอมตะระหว่างนั้น
  กลับมาภายใน 30 วิ เล่นต่อ · เกิน 30 วิ หลุดจากห้อง (ถ้าโฮสต์หายเกิน 30 วิ เพื่อนหลุดทั้งห้อง)
- ทุกเครื่องต้องเป็น v111

งานที่ค้าง (ไว้ทำรอบหน้า)
1. ออนไลน์เล่นโหมดอื่น (ไม่จำกัด / รอด 15-30 นาที / บอสรัช) — ตอนนี้ netStartGame บังคับ S.mode='defendless'
2. โหมดผู้ชม (เข้ามาดูอย่างเดียว ไม่เล่น) — ยังไม่มี
3. TURN server สำหรับเน็ตที่ต่อตรงไม่ได้ — เพิ่มใน NET_ICE.config.iceServers
4. เอฟเฟกต์ท่าไม้ตายของเพื่อนบางตัวยังไม่ครบ (netAura เป็นแบบทั่วไป)
5. บัค "เริ่มเกมแล้วเสียเลือด" ยังทำซ้ำไม่ได้ — รอรายละเอียดจากการเทส
6. ตั้งค่า "เข้ากลางเกม" ได้เฉพาะในห้องรอ (ระหว่างเล่นยังเปลี่ยนไม่ได้)
