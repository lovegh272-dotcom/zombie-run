ระบบใหม่
- เฮลิคอปเตอร์ถอนตัว (ทุกโหมด ยกเว้นโหมดอพยพ): ฆ่าบอสแล้วเฮลิลงจอดห่างจุดบอส ~170px ค้าง 18 วิ
  ยืนในวง H 1.2 วิ = จบรอบทันที เหรียญ x(1 + 0.5 x บอสที่ฆ่า) สูงสุด x4 | เข้าประตูมิติ = ไปสเตจต่อ (เฮลิหายไป)
  ไม่ขึ้นภายในเวลา เฮลิบินออกไป | ตายตามปกติได้เหรียญเท่าเดิม (ไม่หักเพิ่ม)
- เหตุการณ์สุ่ม (ทุก 50–90 วิ เหมือนเดิม) เพิ่ม 3 แบบ + ฝูงบุกแบบใหม่:
  🌕 พระจันทร์เลือด 20 วิ: ซอมบี้เกิด x1.6 เร็ว x1.12 | XP x1.5 หัวใจ/ไอเท็มดรอป x2 | จอขอบแดง
  🪂 เสบียงร่มชูชีพ 26 วิ: กล่องหล่นห่าง 520–720px มีลูกศรชี้ เก็บได้ = เปิดหีบ + 30 เหรียญ
  👑 หัวหน้าซอมบี้ทอง 22 วิ: ก็อบลินทองเลือดหนา วิ่งหนี ฆ่าได้ = หีบ + XP เยอะ + 50 เหรียญ
  🧟 ฝูงบุก: 50% ล้อมรอบแบบเดิม / 50% บุกจากทิศเดียว (หนาแน่นกว่า มีลูกศรแดงบอกทิศ)
  หมอก/ฝนกรด ยังอยู่
- ภารกิจย่อย (เริ่มราว 75–95 วิ แล้วทุก 70–105 วิ ไม่เริ่มตอนมีบอส/เควสยึดพื้นที่/โหมดอพยพ):
  ฆ่า N ตัวใน 30 วิ | ห้ามโดนตี 20 วิ | เก็บ XP N เม็ดใน 30 วิ | ฆ่าตัวใหญ่ 3 ตัวใน 45 วิ
  สำเร็จ = เหรียญ (เพิ่มตามเวลา/สเตจ) + เลือด 15% + 35% ได้ไอเท็ม
- สัญญาต้องสาป: เปิดหีบปกติ 35% ขึ้นให้เลือกคำสาปแลกพร 2 แบบ หรือ "ไม่รับ" (ได้อัปเกรดฟรีเหมือนเดิม) สูงสุด 3 ครั้ง/รอบ
  เลือด −25% ↔ เหรียญ x1.5 | ซอมบี้เร็ว +15% ↔ ดาเมจ +25% | หัวใจไม่ฟื้นเลือด ↔ ยิงเร็ว +20%
  ซอมบี้เกิด +25% ↔ XP +40% เหรียญ x1.2 | วิ่งช้า 10% ↔ อัปเกรดฟรี 2 ครั้ง
- หน้าจบรอบแสดง: ถอนตัว/โบนัสคูณ, ภารกิจสำเร็จ + เหรียญจากภารกิจ/เหตุการณ์, สัญญาที่รับ

แก้ไข
- ยิงไม่โดน (2 สาเหตุ):
  1) กระสุนเร็วกระโดดข้ามซอมบี้ตัวเล็กตอนเฟรมกระตุก -> เช็กการชนตลอดเส้นทางที่กระสุนวิ่งผ่านในเฟรม
  2) ซอมบี้สไปรต์หลายมุมวาดตัวสูงเหนือจุดเท้า แต่เดิมเช็กชนแค่ที่เท้า ยิงโดนลำตัว/หัวในภาพไม่นับ -> เพิ่มจุดชนที่ลำตัว
- กระสุนพิเศษดรอป 1.6% -> 0.6%

เสียง
- เสียงใหม่: เฮลิมา, ใบพัดเฮลิ, ถอนตัวสำเร็จ, เตือนเหตุการณ์, เริ่ม/สำเร็จ/ล้มเหลวภารกิจ, สัญญาต้องสาป, เก็บเสบียง
- เพลงพื้นหลัง: 4 ธีมคอร์ด สลับทุก 8 บาร์ (เดิมวนชุดเดียว) + กลองเบาๆ ตอนเล่น
  บอส/เหตุการณ์ตึงเครียด = ธีมตึง + สแนร์ + จังหวะเร่ง | เฮลิมา = ทำนองสว่างขึ้น
- จบรอบแบบถอนตัวไม่เล่นเสียงแพ้
