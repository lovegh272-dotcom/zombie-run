Zombie Run v108 — เสียงคุยได้ยินกันครบทุกคน

- เสียงคุยแบบทุกคนต่อตรงหากัน: เปิดไมค์แล้วเพื่อนทุกคนในห้องได้ยิน (ไม่ต้องผ่านโฮสต์)
- ขึ้น 🔊 บนหัวคนที่กำลังพูด / แจ้ง "ชื่อ เปิดไมค์" ครบทุกคน (โฮสต์ส่งต่อสถานะให้)
- มีคนเข้าห้องใหม่ขณะเปิดไมค์อยู่ → โทรหาคนใหม่อัตโนมัติ · คนออก → วางสายคนนั้นอัตโนมัติ
- ปุ่ม 🔊 ปิด/เปิดเสียงเพื่อนทั้งหมดพร้อมกัน
- เข้าห้องที่กำลังเล่นอยู่ จะขึ้น "ห้องนี้กำลังเล่นอยู่ · รอจบรอบ" (เดิมขึ้นว่าห้องเต็ม)
- ทุกเครื่องต้องเป็น v108

หมายเหตุ: เสียงระหว่างเพื่อนกับเพื่อน (ไม่ใช่โฮสต์) ต่อตรงกัน ถ้าเน็ตบางคู่บล็อกการต่อตรง คู่นั้นอาจไม่ได้ยินกัน แต่ยังได้ยินโฮสต์ได้ตามปกติ

ทดสอบ: 3 เครื่องขึ้นไป · เพื่อนคนที่ 2 เปิดไมค์ → เพื่อนคนที่ 3 ได้ยินไหม · ดู 🔊 บนหัวตอนพูด
