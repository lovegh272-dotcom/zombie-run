Zombie Run v106 — ไอคอนส่วนที่เหลือ (ใช้รูปที่มีอยู่แล้ว)

- ธาตุ ไฟเผา / พิษ / เย็นจัด / ช็อต: การ์ดอัปเกรดใช้ไอคอนสถานะใหม่ (st_burn st_poison st_freeze st_shock) · ⚡ ในข้อความกลางจอเป็นรูปช็อต
- ตัวละคร: ใช้รูปหน้าแทนอิโมจิ ในหน้าหลัก ล็อบบี้ออนไลน์ (รายชื่อผู้เล่น + แถบเลือกตัว) หน้าหาห้อง เควสตัวละคร เควสฆ่าด้วยตัวละคร หน้าสกิน อันดับ และหน้าปลดล็อกตัวใหม่
- การ์ดเลือกตัวละคร: ตัดอิโมจิซ้ำหน้าชื่อออก (มีรูปหน้าใหญ่อยู่แล้ว)
- ป๊อปอัปชิ้นสร้างในโหมดป้องกัน: ตัวเลขเศษเหล็กเป็นรูปเฟือง
- ร้านอัป / บทสนทนาเนื้อเรื่อง ใช้รูปอยู่แล้ว ไม่ได้แก้
- โปรโตคอลออนไลน์ไม่เปลี่ยน

ทดสอบ: เมนูหลัก, เควส (เลื่อนลงดูเควสตัวละคร), ล็อบบี้ออนไลน์, อัปเลเวลจนเจอการ์ดธาตุ, ป๊อปอัปชิ้นสร้าง
