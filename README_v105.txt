ที่เปลี่ยนในเกม
- หน้าสัญญาต้องสาป: การ์ดกรอบหัวกะโหลก 2 ใบ มีไอคอนคำสาป + ไอคอนพร · ปุ่มไม่รับมีไอคอน
- กระดานเควส: หัวข้อ/รายวัน/รายสัปดาห์/โบนัส/เปลี่ยนเควส เป็นรูป · แต่ละเควสมีไอคอนตามประเภท
- ภารกิจ (ความสำเร็จ) และล็อกอินรายวัน ใช้ไอคอนเหรียญรางวัล/กล่องของขวัญ
- โหมดเนื้อเรื่อง: ไอคอนบท (ใช้รูปแผนที่) ไอคอนประเภทด่าน ดาว 3 ดวงเป็นรูป (ทั้งหน้าเลือกด่านและหน้าจบด่าน)
- คู่หู: ใช้รูปคู่หูจริงแทนอิโมจิ (หน้าอัปเกรด หน้าคู่มือ และ HUD)
- HUD: ไอเทมติดตัว (รองเท้า เกราะ คริ ฟื้นเลือด แบต พลัง เชื้อเพลิง) ชุบชีวิต ขนนก ระดับอันตราย เหตุการณ์ (หมอก ฝน จันทร์เลือด) เป็นรูป
- ข้อความแจ้งเตือนกลางจอ: อิโมจิที่มีรูปแล้วจะแสดงเป็นรูป (เสบียง หัวหน้าซอมบี้ทอง ภารกิจย่อย ไฟ น้ำแข็ง ฯลฯ)
- st_burn/freeze/poison/shock เตรียมไว้สำหรับแสดงสถานะในอนาคต
- โปรโตคอลออนไลน์ไม่เปลี่ยน (เล่นกับ v103/v104 ได้)

ทดสอบ
1. เล่นจนได้สัญญาต้องสาป (หรือเมนูนักพัฒนา) ดูการ์ดใหม่
2. เมนู > เควส / ภารกิจ / รายวัน
3. เมนู > เนื้อเรื่อง ดูดาวและไอคอนด่าน แล้วเล่นจบ 1 ด่าน
4. ในเกม ดู HUD มุมซ้ายบนและข้อความแจ้งเตือนกลางจอ
5. ถ้าเห็นไอคอนเก่า ให้รีเฟรช/ล้างแคช (cache = zrun-v105)
