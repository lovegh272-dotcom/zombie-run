Zombie Run v114
- โหมดอพยพเล่นออนไลน์ได้ (โฮสต์เลือก "อพยพ" ในห้องรอ)
  ทุกคนช่วยเก็บอะไหล่วิทยุได้ (ใครยืนที่อะไหล่ก็นับ) · ใครอยู่ในวงจุดอพยพก็นับเวลาป้องกัน
  เพื่อนเห็นอะไหล่ ตัวเฝ้า จุดอพยพ ลูกศรนำทาง สัญญาณรบกวน และเวลาป้องกันเหมือนโฮสต์ · ชนะแล้วทุกคนขึ้นหน้าชนะ
- ทุกเครื่องต้องเป็น v114

งานที่ค้าง
1. เอฟเฟกต์ท่าไม้ตายของเพื่อน (ท่าที่ใช้สถานะเฉพาะ เช่น thor/mini/ice/plane/dark ยังขึ้นฝั่งโฮสต์ และไม่ส่งให้เพื่อน)
2. TURN server (ต้องสมัครบริการ)
3. บัคเริ่มเกมแล้วเสียเลือด (รอรายละเอียด)
4. ท้าทายรายวัน: คนเข้ากลางเกม/ผู้ชมอาจเห็นแผนที่ไม่ตรงโฮสต์
