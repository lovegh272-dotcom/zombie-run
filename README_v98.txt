Zombie Run v98 – แชทห้องรอจาง/ย่อได้ · ปุ่ม 🛠 ลากได้ · เอฟเฟกต์สกิลเห็นทั้งสองจอ · แถบเลือกไม่เด้ง

💬 แชทห้องรอ
- ไล่จาง: ด้านบนจางหาย → ด้านล่างเข้ม · สูงไม่เกินประมาณ 1/3 จอ (เก็บ 15 ข้อความล่าสุด ปัดเลื่อนได้)
- ปุ่ม ▾ ย่อแชท → เหลือปุ่ม 💬 (มีตัวเลขข้อความใหม่) กดอีกครั้งเพื่อขยาย · จำสถานะไว้

🛠 ปุ่มนักพัฒนา
- ลากย้ายไปตรงไหนก็ได้ (แตะเฉยๆ = เปิด/ปิดแผง) · จำตำแหน่งไว้
- ในแผงมีปุ่ม "🙈 ซ่อนไอคอน" (เปิดกลับได้ที่ ตั้งค่า > 🛠 ไอคอนนักพัฒนา)
- เร่งเวลาเหลือ ×1 ×2 ×3 ×5 (เอา ×10 ออก)
- ใหม่: "⏸ หยุดเวลาสร้าง" (โหมดป้องกันรถ) — เวลาพักสร้างไม่ลดจนกว่าจะปิด
  (ปกติเวลาสร้างยังนับถอยหลังตามเดิม)

✨ เอฟเฟกต์สกิล/อาวุธ (ออนไลน์)
- เครื่องเพื่อนเห็นวงระเบิด/วงสกิล ฟ้าผ่า ภาพแตกกระแทก และระเบิดมือที่ลอย จากเครื่องโฮสต์แล้ว (เดิมเห็นแค่ซอมบี้ตาย)
- สกิลของเพื่อนไม่ซ้อนเอฟเฟกต์สองชั้นบนจอตัวเอง

🏠 ห้องรอ
- เลื่อนแถบตัวละคร/แผนที่/ความยากแล้วไม่เด้งกลับ (จำตำแหน่งเลื่อน + ไม่รีเฟรชหน้าทุก 2 วิจากค่าปิงแล้ว)
- เปิดห้องครั้งแรก แถบตัวละครเลื่อนไปหาตัวที่เลือกอยู่

ทดสอบแล้ว: Chromium 2 หน้าจำลองออนไลน์ — แถบเลื่อนไม่เด้ง, ย่อแชท, ลากปุ่ม 🛠, หยุดเวลาสร้าง, เอฟเฟกต์/ฟ้าผ่าส่งถึงเครื่องเพื่อน, ซ่อนไอคอน (ไม่มี error)
