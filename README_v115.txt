Zombie Run v115
- แก้ร่างแปลงนักล่าคลั่งของเพื่อน: เดินมีท่าเดินตามการขยับของเพื่อนจริง (เดิมขยับตามจอยของเครื่องเรา ทำให้ดูยืนนิ่ง/ลอย)
- ท่าฟันของร่างยักษ์/ท่าฟันปกติของเพื่อนไม่ถูกตัดกลางคันระหว่างรอภาพจากโฮสต์
- ออนไลน์เหมือน v114 (เล่นด้วยกันได้)

งานที่ค้าง
1. เอฟเฟกต์ท่าไม้ตายของเพื่อนที่ใช้สถานะเฉพาะ (thor/mini/ice/plane/dark ฯลฯ) ยังขึ้นฝั่งโฮสต์ ไม่ส่งให้คนอื่น — ต้องไล่ทีละท่า
2. TURN server (ต้องสมัครบริการ)
3. บัคเริ่มเกมแล้วเสียเลือด (รอรายละเอียด)
4. ท้าทายรายวัน: คนเข้ากลางเกม/ผู้ชมอาจเห็นแผนที่ไม่ตรงโฮสต์
