Zombie Run v99 – คุยด้วยเสียง 🎤

วิธีใช้
- ห้องรอ: ปุ่ม 🎤 อยู่ซ้ายช่องพิมพ์แชท (ขึ้นเมื่อมีเพื่อนในห้อง) · ในเกม: ปุ่ม 🎤 อยู่ซ้ายปุ่ม 💬 (แถบบนขวา)
- กด 🎤 = เปิด/ปิดไมค์ของเรา (กดครั้งแรก iPhone จะถามอนุญาตใช้ไมโครโฟน)
  · ไมค์เปิด = 🎙️ กรอบเขียว (กำลังพูดจะเขียวสว่าง) · ไมค์ปิด = 🎤 ขีดฆ่า
- ปุ่ม 🔊 / 🔇 (ขึ้นเมื่อเพื่อนเปิดไมค์) = เปิด/ปิดเสียงเพื่อน · ถ้าเป็น 🔈 แปลว่าเบราว์เซอร์ยังไม่ยอมเล่นเสียง → แตะ 1 ครั้ง
- เพื่อนกำลังพูด: ขึ้น 🔊 หน้าชื่อเพื่อนบนหัวตัวละคร และกรอบปุ่มเสียงเป็นสีทอง
- เปิดไมค์ในห้องรอแล้ว ยังคุยต่อได้ตอนเข้าเกม · ออกจากห้อง = ปิดไมค์และวางสายอัตโนมัติ
- กันเสียงสะท้อน/ตัดเสียงรบกวน/ปรับระดับเสียงอัตโนมัติ (ของเบราว์เซอร์) เปิดไว้แล้ว

ข้อควรรู้ (iPhone)
- ตอนเปิดไมค์ iOS อาจทำให้เสียงเกมเบาลง หรือเสียงไปออกลำโพงหูฟังโทรศัพท์ (ข้อจำกัดของ iOS) → ใส่หูฟังดีที่สุด
- สลับแอป/ล็อกจอ = เสียงตัด (เหมือนตัวเกม)
- ใช้เน็ตเพิ่มประมาณ 30–50 kbps ต่อคน

อื่นๆ: กล่องแชทห้องรอกว้างขึ้นเล็กน้อย (มีที่ให้ปุ่มไมค์)

ทดสอบแล้ว: Chromium 2 หน้า + ไมค์จำลอง — เปิด/ปิดไมค์, เพื่อนได้รับเสียง, ปิดเสียงเพื่อน, เสียงต่อเนื่องตอนเข้าเกม, ป้ายกำลังพูด (ไม่มี error)
ยังไม่ได้ทดสอบ: เสียงจริงระหว่าง iPhone 2 เครื่อง (สำคัญที่สุดของเวอร์ชันนี้)
