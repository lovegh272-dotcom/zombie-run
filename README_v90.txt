Zombie Run v90 – ออนไลน์ขั้นที่ 2: เข้าเกมป้องกันรถด้วยกัน (2 คน)

ใหม่
- ในห้องออนไลน์ เมื่อทั้งสองคนกด ✅ พร้อม แล้วโฮสต์กด ▶ เริ่มเกม → ทั้งสองเครื่องเข้าโหมด 🚚 ป้องกันรถ (ไม่จำกัดคลื่น) พร้อมกัน
  ใช้แผนที่และความยากของโฮสต์ (ผู้เข้าร่วมไม่ต้องปลดล็อกแผนที่นั้น)
- เห็นเพื่อนเดินในจอ มีชื่อ + หลอดเลือดเหนือหัว และมีลูกศรชี้เมื่อเพื่อนอยู่นอกจอ
- ผู้เข้าร่วมยิงอัตโนมัติใส่ซอมบี้ตัวเดียวกัน (ดาเมจ/ความเร็วยิงจากอัปเกรดของตัวเอง และแรงขึ้นตามเลเวลของทีม)
  v90 ทุกตัวละครของผู้เข้าร่วมยิงกระสุนธรรมดาก่อน (อาวุธเฉพาะตัวมาใน v92)
- ซอมบี้ไล่คนที่อยู่ใกล้กว่า · ผู้เข้าร่วมโดนตี/โดนกรดได้
- ผู้เข้าร่วมล้ม → โฮสต์ไปยืนในวงประข้างๆ 3 วิเพื่อชุบ (ฟื้นครึ่งเลือด) · ผ่านคลื่นแล้วฟื้นเองและได้เลือดคืน 30%
- รถ/สิ่งก่อสร้าง/เศษเหล็ก/คลื่น/ประกาศบนจอ ตรงกันทั้งสองเครื่อง
- เกมจบ (รถพัง หรือโฮสต์ตาย) → ทั้งคู่เห็นหน้าสรุป ได้เหรียญตามจำนวนที่ฆ่า/เวลา และมีปุ่ม "🌐 กลับห้องออนไลน์" เพื่อเล่นรอบต่อ
- ถ้าเพื่อนหลุดกลางเกม โฮสต์เล่นต่อคนเดียวได้ · ถ้าโฮสต์หลุด ผู้เข้าร่วมกลับไปหน้าออนไลน์
- ระหว่างเล่นออนไลน์ โฮสต์เลือกอัปเกรดตอนเลเวลอัปให้อัตโนมัติ (กันเกมของเพื่อนค้าง)
- โฮสต์กดหยุด/อยู่ในเมนู → เครื่องผู้เข้าร่วมขึ้น "⏸ รอโฮสต์..."

ยังไม่มีใน v90 (ตามแผน)
- โฮสต์ตายแล้วยังจบเกมทันที (ระบบชุบสองทาง → v91)
- ผู้เข้าร่วมยังใช้สกิล/สร้างป้องกันไม่ได้ (สกิล → v92, สร้างร่วมกัน → v93)
- ผู้เข้าร่วมเก็บหัวใจ/ของดรอปไม่ได้

วิธีทดสอบ (2 เครื่อง)
1. ปิดแอปแล้วเปิดใหม่ทั้งสองเครื่องให้เป็น v90 (ถ้าเวอร์ชันไม่ตรง จะขึ้นเตือนตอนเข้าห้อง)
2. สร้างห้อง/เข้าห้อง → พร้อมทั้งคู่ → โฮสต์กดเริ่มเกม
3. เช็ก: เห็นกันเดินลื่นไหม · ซอมบี้ตรงกันไหม · ผู้เข้าร่วมยิงแล้วซอมบี้ตายจริงไหม
4. ให้ผู้เข้าร่วมไปยืนกลางฝูงจนล้ม → โฮสต์ไปยืนข้างๆ 3 วิ → ต้องฟื้น
5. เล่นไปหลายคลื่นจนมีซอมบี้เยอะ แล้วดูว่าเครื่องผู้เข้าร่วมกระตุกไหม
6. ปล่อยให้รถพัง → ทั้งคู่ต้องเห็นหน้าสรุป → กด "กลับห้องออนไลน์" แล้วเริ่มรอบใหม่ได้
